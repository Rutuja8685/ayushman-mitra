# Ayushman Mitra

A React demo experience for exploring Ayushman Bharat / PM-JAY information through a simple, accessible web interface.

## Features

- Home page with primary navigation
- About Scheme information page
- Hospitals page
- Login / registration flow demonstration
- Dashboard and team-oriented page components
- Responsive styling with plain CSS

## Technology

- React 19
- JavaScript
- HTML and CSS
- Create React App toolchain

## Run locally

~~~bash
npm install
npm start
~~~

The development server opens at http://localhost:3000.

### Production build

~~~bash
npm run build
~~~

## Project structure

- src/App.js — application shell and navigation state
- src/pages/ — home, scheme, hospitals, login, dashboard, and team views
- src/App.css — application styling

## Disclaimer

This is an independent educational/demo project. It is not an official government service and should not be used to submit real beneficiary information.
